IDEA NOTE

経済イベント・マクロ因果マップのアイデア

経済ニュースや政策イベントを入力すると、各種経済指標・市場指標へどのように連鎖して影響するかを一目で見られるツールの構想。

作りたいものは、経済ニュースや政策イベントを入力すると、それが各種経済指標・市場指標にどう連鎖して影響するかを一目で見られるツール。

たとえば「円安」「原油高」「米利下げ」「日銀利上げ」「中国景気悪化」「賃上げ加速」「消費税増税」「地政学リスク」などを入力すると、一次影響・二次影響・副作用・確認すべき統計が因果マップとして表示される。

目的は、単純な予測装置を作ることではない。「円安なら日本株高」「原油高なら物価上昇」みたいな一段論法ではなく、現実には同時に複数の経路が走るので、その経路を見える化したい。

円安を入力した場合の例

内需へのマイナス経路

円安 → 輸入物価上昇 → 企業物価上昇 → 消費者物価上昇 → 実質賃金低下 → 家計消費悪化 → 内需企業にマイナス

輸出企業へのプラス経路

円安 → 外貨建て売上・利益の円換算額増加 → 輸出企業・海外売上企業の利益上振れ → EPS上昇 → 株価にプラス

金利経由のマイナス経路

円安 → インフレ圧力 → 日銀利上げ観測 → 長期金利上昇 → PER低下圧力 → 株価にマイナス

このように、同じイベントの中にプラス要因とマイナス要因が同時に存在することを表現したい。

表示したい指標

為替、輸入物価、企業物価、CPI、コアCPI、実質賃金、家計消費、実質消費支出、小売売上、企業利益率、設備投資、政策金利、長期金利、PER、EPS、株価、国債、住宅ローン、インバウンド、貿易収支、経常収支など。

各矢印に持たせたい情報

  • 上がる方向なのか、下がる方向なのか。
  • 影響がすぐ出るのか、遅れて出るのか。
  • 条件次第で逆方向にもなり得るのか。
  • 誰にとってプラスで、誰にとってマイナスなのか。
  • その影響を確認するには、どの統計を見ればよいのか。

たとえば「内需が弱る」と言うだけでは雑なので、その場合は実質賃金、実質消費支出、小売売上、消費者態度指数、数量ベースの販売動向などを見る、というところまで示したい。

本質

このツールの本質は、「経済が連鎖して動く地図」を作ること。用語説明ではなく、イベントから指標への因果関係を、仮説として整理するためのマップにする。

作り始め方

将来的に作るなら、最初は完璧なシミュレーターではなく、イベントごとのテンプレート型の因果マップから始める。その後、統計データやニュース、企業業績、金利、為替、株価などをつなげて、実際にどの経路が強く出ているかを確認できるようにする。
